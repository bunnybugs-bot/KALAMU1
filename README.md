## 📖 Description
Site web officiel de l'Association Kalamu, une organisation culturelle à but non lucratif dédiée à la promotion de la lecture et de l'écriture en Afrique. Un site moderne, responsive et accessible qui met en valeur la mission de l'association.

## 🪶 À Propos de Kalamu
**Kalamu** signifie "plume" en swahili et en arabe. Elle symbolise le savoir, la mémoire et la transmission spirituelle. Notre association s'engage dans la promotion de la lecture, de l'écriture et de la transmission culturelle en Afrique.

### 🎯 Notre Vision
Une société où chaque enfant et adulte a accès au livre et où l'écrit perpétue les trésors de l'oralité.

### 🚀 Notre Mission
- 📚 Promouvoir la lecture pour tous
- ✍️ Encourager l'écriture créative
- 🌍 Valoriser le patrimoine oral africain
- 🎭 Organiser des événements culturels autour du livre
- 👥 Soutenir les auteurs africains émergents

## ✨ Fonctionnalités du Site

### 🏠 **Accueil**
- Design spectaculaire avec dégradés colorés
- Logo animé avec effet de lueur
- Slogan animé mot par mot
- Boutons d'action avec effets visuels

### 📋 **Sections Principales**
- **À Propos** : Vision, mission et signification du nom "Kalamu"
- **Objectifs** : Les 5 objectifs principaux avec cartes interactives
- **Activités** : Clubs de lecture, masterclass, ateliers d'écriture
- **Public Cible** : Cartes colorées pour chaque catégorie
- **Partenaires** : 5 catégories de partenaires
- **Nos Membres** : Carousel interactif avec 11 membres
- **Contact** : Informations complètes avec design moderne

### 🎨 **Design & UX**
- **Responsive Design** : Optimisé pour tous les appareils
- **Animations CSS** : Transitions fluides et effets visuels
- **Glassmorphism** : Effets de transparence et flou
- **Navigation** : Menu fixe avec indicateur de section active
- **Carousel** : Navigation par slides avec auto-play
- **Accessibilité** : Support ARIA et navigation clavier

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique et accessible
- **CSS3** : Variables CSS, animations, gradients, glassmorphism
- **JavaScript** : Interactions, carousel, animations scroll

## 🚀 Installation

1. **Cloner le dépôt**
   ```bash
   git clone https://github.com/association-kalamu/website.git
   cd website
   ```

2. **Ouvrir le site**
   - Ouvrez `index.html` dans votre navigateur
   - Ou utilisez un serveur local :
   ```bash
   # Avec Python
   python -m http.server 8000
   
   # Avec Node.js
   npx serve .
   ```

3. **Aucune installation supplémentaire requise !**

## 🎨 Personnalisation

### 🖼️ Images
- Remplacez `logo.PNG` par le logo officiel
- Ajoutez les photos des membres dans le dossier
- Personnalisez l'image de fond hero (`kalamu.jpeg`)

### 🎨 Couleurs
Modifiez les variables CSS dans `styles.css` :
```css
:root {
    --primary-color: #ff6b35;    /* Orange principal */
    --secondary-color: #f7931e;  /* Orange secondaire */
    --complementary-color: #2e8b57; /* Vert complémentaire */
    --dark-color: #2c3e50;       /* Bleu foncé */
}
```

### 📱 Réseaux Sociaux
Mettez à jour les liens dans la section contact :
```html
<a href="https://facebook.com/kalamu">Facebook</a>
<a href="https://instagram.com/kalamu">Instagram</a>
<a href="https://youtube.com/kalamu">YouTube</a>
```
